# Código de conduta

Este projeto segue o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo:

- Trate as pessoas com respeito, em issues, PRs e revisões. Critique o código, não quem escreveu.
- Sem assédio, ofensa, ataque pessoal ou exposição de dados de outras pessoas.
- Quem mantém o projeto pode editar ou apagar comentários, issues e PRs que desrespeitem estas regras, e bloquear quem insistir.

Para relatar um problema de conduta, escreva em privado para quem mantém o projeto (perfil [@nerigleston](https://github.com/nerigleston) no GitHub). O relato fica em sigilo.
